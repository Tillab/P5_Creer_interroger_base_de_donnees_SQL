# Créer et interroger une base de données immobilière avec SQL
Projet 5 OpenClassrooms

### Contexte et démarche
Dans ce projet, j’ai créé une base de données destinée à centraliser les informations sur les transactions immobilières d’un réseau national d’agences. Les données regroupaient des transactions immobilières, des données de population de l’INSEE et des données publiques décrivant les régions françaises.
Dans l’environnement Lakehouse de Databricks, j’ai créé les tables et écrit des requêtes SQL pour répondre à des questions métier portant sur le marché immobilier.

### Résultats et impact
La structure de données et les requêtes développées fournissent une base pour analyser les conditions des marchés locaux et aider les agences régionales à mieux accompagner leurs clients.

**Compétences :** SQL, modélisation des données, Databricks, intégration de données, prise en compte du RGPD.

**Limite :** La qualité et la portée des analyses dépendent de l’exhaustivité, de la cohérence et de la couverture géographique et temporelle des données sources.
